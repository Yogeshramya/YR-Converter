# YR-Converter

A premium, high-fidelity media converter utility built with Next.js, React, and Tailwind CSS.

## Features

- **Pure Client-Side Local Conversion**: Extract and encode audio tracks from local video files directly inside your browser. Your media files are never uploaded to any server, ensuring total privacy.
- **Direct YouTube Downloader**: Stream high-quality audio (MP3) and video (MP4) from YouTube links directly to your browser's default downloads folder without ad-heavy redirects.
- **Rich User Experience**: Clean, modern glassmorphic interface with real-time conversion progress indicators, smooth micro-animations, and audio preview playback.

## Getting Started

First, install the dependencies and run the development server:

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) with your browser to see the application.
